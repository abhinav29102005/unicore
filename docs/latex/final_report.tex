\begin{abstract}
Modern universities manage student records, hostel allocation, library inventory, and examination processing through disconnected systems, leading to data redundancy, inconsistency, and security risks. This project presents the University Integrated Management System (UIMS), a centralized PostgreSQL relational platform normalized to Boyce-Codd Normal Form (BCNF) across 8 domain schemas and 35+ tables.
\end{abstract}

\section{Problem Statement}
Fragmented systems create five critical operational failure modes:
\begin{enumerate}
    \item \textbf{Data Duplication:} Redundant address entries across modules.
    \item \textbf{Inconsistency:} Mismatched records during partial updates.
    \item \textbf{Resource Tracking:} Manual tracking of bed capacities and book copies.
    \item \textbf{Transaction Hazards:} Double-allocation of rooms during peak rushes.
    \item \textbf{Security Gaps:} Unscoped permissions across modules.
\end{enumerate}
